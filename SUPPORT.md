# Support

ContentLens is in planning and has no supported production build.

## Where to ask

- Use a GitHub Discussion when enabled for design questions and general help.
- Use a proposal issue for a scoped feature or product-contract change.
- Use a bug issue for an error in published documentation or future builds.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

## Information to provide

- Document, version or commit SHA.
- Browser and operating system when relevant.
- Expected and observed behavior.
- Minimal reproduction without personal browsing data.
- Logs with tokens, URLs and identifiers removed.
- A ContentLens diagnostic export only after reviewing its redacted summary.

Do not paste raw platform HTML, content titles, full URLs, account identifiers, model prompts or profile exports into a public issue. A diagnostic error code and affected capability should be enough for initial triage.

## Scope

Maintainers may help with ContentLens contracts, documented workflows and released builds. They cannot provide support for:

- Third-party platform account problems.
- Provider outages.
- Custom models or plugins outside supported contracts.
- Lost encryption passphrases or deleted provider data.
- Circumventing browser or platform security controls.

## Service level

Support is best effort. Security reports use separate response targets. A public roadmap item does not guarantee delivery or a release date.
