# Addendum de feedback nativo do X

| Campo | Contrato atual |
| --- | --- |
| Adapter | `x-adapter@1` |
| Addendum | `x-native-feedback@1` |
| Fixture | `x-fixtures@1` |
| Ação permitida | `x:not-interested-post` |
| Superfícies declaradas | following, for-you, replies, quoted-posts, threads |
| Identidade | post ID estável na mesma instância de página |
| Evidência positiva | confirmação visível ligada ao mesmo post |
| Timeout | 2 segundos |
| Cooldown mínimo | 24 horas |
| Undo | não comprovado, declarar irreversível |
| Live smoke | ausente |
| Estado | `unsupported` em todas as superfícies |

Antes da promoção, uma conta e posts controlados devem comprovar menu, rótulo e
confirmação positiva. Mute, block, follow, unfollow, like, repost e report são
proibidos.
