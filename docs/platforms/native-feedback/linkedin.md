# Addendum de feedback nativo do LinkedIn

| Campo | Contrato atual |
| --- | --- |
| Adapter | `linkedin-adapter@1` |
| Addendum | `linkedin-native-feedback@1` |
| Fixture | `linkedin-fixtures@1` |
| Ação permitida | `linkedin:reduce-similar` |
| Superfícies declaradas | feed, reposts, promoted-posts, comment-preview |
| Identidade | post ID estável na mesma instância de página |
| Evidência positiva | confirmação visível ligada ao mesmo post |
| Timeout | 2 segundos |
| Cooldown mínimo | 24 horas |
| Undo | não comprovado, declarar irreversível |
| Live smoke | ausente |
| Estado | `unsupported` em todas as superfícies |

Antes da promoção, uma conta e posts controlados devem comprovar o controle
público de reduzir conteúdo semelhante e sua confirmação positiva. Unfollow,
connect, disconnect, endorse, react e report são proibidos.
